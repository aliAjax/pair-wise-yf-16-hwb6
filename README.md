# hxyfront-62004 滑雪板打蜡准备台

源提示词编号：6

面向滑雪板调校店的打蜡准备工作台。技师为每块板登记品牌、长度、板型、蜡型、刷具编号和底板损伤，系统按雪温温区追踪刷具的软蜡残留，防止赶工时刷两下就换温区造成串蜡。

## 工作规则

- **选蜡型即占用刷具**：蜡型对应低温 / 中温 / 暖温三个温区，登记工单时占用选定编号的刷具。
- **换温区先清洁**：完工后刷具释放但带有本温区残留；同温区可直接续用，跨温区前必须在刷具架或待准备工单上「登记清洁完成」。
- **待准备闸口**：刷具未清洁（跨温区）或底板有损伤却没写修补位置时，「开始打蜡」禁用，工单停在待准备并显示阻断原因。
- **完工释放**：打蜡中登记侧刃 / 底刃结果后完工，刷具释放为空闲并记录残留温区。
- **客户历史**：按客户保留每次完工的蜡型、刷具编号、刃角结果、损伤与修补位置，可导出 JSON 摘要。

页面还包含刷具架状态、板型 / 完工状态筛选和待准备、打蜡中、完工、待清洁刷具计数。数据保存在浏览器 localStorage。
