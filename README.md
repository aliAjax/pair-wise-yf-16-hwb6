# hxyfront-62004 滑雪板调校维护 · 打蜡准备台

源提示词编号：6

面向滑雪板调校店的打蜡准备台前端，按雪温温区调度蜡与刷具：

- 每块板登记品牌、长度、板型、刃角、蜡型与底板损伤
- 选定蜡型后自动占用对应温区的空闲刷具（优先同温区残留，其次已清洁刷具）
- 刷具换温区前必须登记清洁完成，未清洁时下一块板停在待准备
- 底板损伤未登记修补位置不能开始打蜡，可在工单上补登记
- 完工释放刷具（刷毛留下当次蜡的温区残留），客户历史保留当次蜡型、刷具与刃角结果

页面包含：刷具架（温区占用与清洁）、蜡型温区表、登记新板表单、工单队列（状态/板型筛选）、客户历史维护记录。

## 技术栈

React + Vite + TypeScript
